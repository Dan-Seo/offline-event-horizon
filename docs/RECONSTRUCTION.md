# 사진에서 작은 장소로 — 다음 개인 기여를 위한 파이프라인

**현재 상태:** 실제 촬영·COLMAP 복원은 아직 수행하지 않았다. 현재 배포의 자연물은 절차적으로 생성한 형상이다. 아래 절차와 재투영 검사 도구를 준비했으며, 검사기의 좌표 변환은 명시적인 합성 수치 예제로만 검증했다.

## 1. 직접 수집

허가된 고정 대상 하나를 여러 높이와 방향에서 충분히 겹치게 촬영한다. 반짝이는 물, 움직이는 잎, 반복 무늬는 첫 복원 대상으로 피한다. 초점·초점거리·노출이 자주 바뀌지 않도록 한다. 대상 주변의 이동 경로, 사진 수, 촬영 조건, 알려진 치수 하나를 기록한다. 얼굴·번호판 등은 담지 않는다. 원본은 `research-data/capture/images/`에 로컬 보관한다.

## 2. 기존 도구로 복원

[COLMAP 공식 튜토리얼](https://colmap.github.io/tutorial.html)에 따라 특징 추출·매칭·희소 복원·필요한 경우 밀집 복원을 수행한다. 선택한 버전과 실제 명령, 실패한 사진/실패 이유를 기록한다. 모든 중간 결과를 성공한 것처럼 묶지 않는다. 원본 희소 모델을 텍스트로 내보낸다.

```sh
colmap model_converter --input_path research-data/capture/sparse/0 --output_path research-data/capture/model-text --output_type TXT
python scripts/reconstruction_report.py research-data/capture/model-text --input-images 80 --output research-data/capture/report.json
```

`80`은 예시다. 실제 입력 사진 수로 바꾼다. 변환 출력 폴더는 미리 만든다. 검사기는 SIMPLE_PINHOLE, PINHOLE, SIMPLE_RADIAL, RADIAL을 지원한다. 다른 카메라는 조용히 잘못 투영하지 않고 오류를 낸다. 필요하면 COLMAP에서 영상을 왜곡 보정해 PINHOLE 모델로 내보낸다.

검사기는 텍스트 모델의 world→camera 포즈를 적용하고, 등록된 관측의 재투영 오차를 직접 계산한다. 사진 등록 비율, 희소 점 수, 추적 길이, 카메라 뒤쪽 관측, 입력 파일 해시를 함께 기록한다. 원본 파일 포맷과 포즈 정의는 [COLMAP 문서](https://colmap.github.io/format.html)를 따른다.

**이 오차는 동일 복원에 사용한 관측의 잔차다.** 새로운 시점의 정확도, 실제 치수 오차, 복원 완전성 또는 SLAM 궤적 정확도가 아니다. 독립 검증 사진과 기준 치수를 별도로 남긴다.

## 3. 실시간 자산으로 정리

Blender에서 원본 복제본을 정리하고 좌표축·바닥·실제 기준 길이를 맞춘다. 최적화 전후 형상을 동일 카메라에서 비교한다. 제안 예산은 hero 50k triangles 이하, distant 8k 이하, 재질 4개 이하, 텍스처 최대 2048px, GLB 5MB 이하이다. 목표를 넘으면 이유와 측정 결과를 남긴다.

내보낼 때 `scene.gltf`/GLB의 Y-up, 적용된 변환, 중심점, 노멀, UV, 텍스처 누락을 확인한다. `world.ts`의 Cathedral처럼 낮은 비용의 절차적 형상을 먼저 보여주고 모델을 나중에 교체하는 경로를 재사용할 수 있다. 실제 자산이 생기기 전에는 빈 네트워크 요청이나 가짜 복원 모델을 제품에 추가하지 않는다.

## 4. 비교할 증거

| 단계      | 보관할 것                                        |
| --------- | ------------------------------------------------ |
| 수집      | 직접 작성한 촬영 경로·조건·사진 수               |
| 복원      | 명령, 버전, 등록률, 오차 분포, 실패 사례         |
| 최적화    | 원본/최적화 GLB, 삼각형·텍스처·파일 크기         |
| 표시      | 같은 시점의 화면, frame p50/p95, 다운로드 시간   |
| 개인 기여 | 본인이 결정하고 수정한 내용, 사용한 AI·외부 도구 |

독립 기준이 생기면 실제 형상의 오차와 단순화 비율 사이 관계를 추가로 분석한다. 그때의 데이터와 결과가 CV/CEE와 연결되는 실질적인 포트폴리오 근거가 된다.
