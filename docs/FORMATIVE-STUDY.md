# 짧은 체험 평가 계획 — 아직 시행하지 않음

목적은 조작의 마찰과 다시 머무르고 싶은 장소를 찾는 것이다. 치료 효과를 검증하는 실험으로 소개하지 않는다. 현재 수집된 응답은 없다. 앱에는 분석 추적이나 자동 데이터 전송을 넣지 않았다.

## 진행안

업무 후 화면 사용 경험이 있는 성인 5–8명을 소규모 사용성 점검에 초대한다. 참여와 중단은 자유이며, 이름·회사·건강 정보는 받지 않는다. 화면 녹화나 인용은 별도로 동의를 받은 경우에만 사용한다. 대학 소속 정식 연구로 전환할 때는 담당 연구자와 해당 기관의 절차를 먼저 확인한다.

진행자는 처음에 “마음대로 머무르거나 움직여 보세요. 원하면 언제든 끝내셔도 됩니다”라고 설명한다. 평가 중에는 계속 말하게 하지 않고 조용히 체험하게 한다.

1. 시작 전: 지금 편안함을 0–10으로 자율 평가. 기기·브라우저 기록.
2. 자유 체험 약 5분: 조작 설명을 찾아야 했는지, 시점 제어에 들어갔는지, 자동 이동을 멈출 수 있었는지 관찰. 도움이 필요하면 제공하고 횟수 기록.
3. 종료 후: 편안함 0–10, 조작 쉬움 1–7, 다시 머무르고 싶음 1–7. 원하면 답하지 않아도 된다.
4. 짧은 질문: “멈춰 보고 싶었던 곳은?”, “불편하거나 부담스러웠던 순간은?”, “한 가지만 바꾼다면?”

3.0에서는 같은 출발 지점에서 **자유 비행**, **PILGRIM에 맡기기**, **정지 관찰** 세 조건을 비교할 수 있다. 아직 시행하지 않은 계획이다. 세 조건의 여섯 가지 순서를 균형 있게 배정하고, 각 조건은 최대 5분으로 두되 언제든 멈출 수 있게 한다. 조건 사이에 쉬는 시간을 제공한다. 실제 사용한 모드와 수동 개입 횟수도 기록한다. 정지 관찰을 기존 WANDER로 바꾸면 그 사실을 별도 조건으로 명시하고 둘을 합치지 않는다.

종료 후 편안함, 지각된 통제감, 부담 없이 바라볼 수 있었는지, 다시 머무르고 싶은지를 탐색적 문항으로 묻는다. 어지러움·메스꺼움·눈의 피로가 생기면 즉시 중단하고 중단 사례를 남긴다. 이 자체 제작 문항을 검증된 임상 척도라고 소개하지 않는다. 작은 표본의 전후 점수는 인과적 효과나 통계적 유의성으로 해석하지 않는다. 그래픽에 대한 기대, 기기 차이, 진행자 영향도 함께 적는다.

`/lab`의 궤적·센서 파일은 공학 검증 자료다. 사람의 회복감에 관한 증거로 대체하지 않는다. 일반 화면에는 자동 행동 기록이나 외부 전송을 추가하지 않았다. 아래 빈 서식은 향후 진행자가 동의 후 작성할 자료이며 참가자 응답이 아니다.

## 기록 형식

개인정보 없는 ID를 사용하고 원본 응답은 공개 저장소 밖에 보관한다. `research-data/`는 Git에서 제외했다.

```csv
participant_id,browser,device,start_mode,minutes,comfort_before,comfort_after,control_ease,return_interest,help_count,early_stop,preferred_place,friction_notes
```

공개 결과에는 시행일, 모집 방식, 실제 인원, 빠진 응답, 중단 사례, 분포 또는 개별 익명 점을 표시한다. 좋은 의견만 뽑지 않는다. 문제 하나를 고친 뒤 소수 재시험으로 개선 여부를 확인한다.
